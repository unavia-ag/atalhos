# Unavia · atalhos

Páginas estáticas (GitHub Pages) que os avisos do **Unavia Monitor** abrem com um toque.

| Página | Para quê |
|---|---|
| `copel.html` | Chamado de falta de energia na COPEL: SMS pronto ("SL" + nº da unidade para 28593), WhatsApp (41) 3013-8973 ou 0800 51 00 116. |

**Nenhum dado fica aqui.** O número da unidade vem no próprio link, depois do `#`
(`copel.html#uc=12345678`). A parte depois do `#` não é enviada a servidor nenhum: a página monta os links
no celular de quem tocou. O repositório é público só porque o GitHub Pages grátis exige.

Fonte dos canais da COPEL: copel.com › Falta de energia.
